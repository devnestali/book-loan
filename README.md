# 📚 Book Loan

Book loan was designed to manage the catalog of available books and control access for different types of users. In the application, users and clients can view all books available for lending, including information such as the book title, publisher, edition, author, and availability. Administrators have full access to the system, allowing them to manage both the books and the records of users and clients, with the ability to add, edit, or remove entries as needed. This system provides a practical and intuitive solution for managing book loans, making administration easier and offering a simple and efficient experience for all user roles.

## 📇 Main Features
- **Pages:** All the pages from the app is located here (`src/app/pages`).
- **Components:** All of the components used around the app is located here (`src/app/components`)
- **Guards:** The Guards for users permissions and auth is placed here (`src/app/guards`)
- **Helpers:** All the functions to help transform data is located here (`src/app/helpers`)
- **Interceptors:** The Interceptors to intercept errors, token and loading is placed here (`src/app/interceptors`)
- **Modals:** All of the modals used in this application is located on this folder (`src/app/modals`)
- **Models:** Models for data used in API RestFul is placed here (`src/app/models`)
- **Modules:** Shared-Modules or External Tools is located here (`src/app/modules`)
- **Services:** All the services used in this app to communicate with API is placed here (`src/app/services`)
- **Utils**: Functions that is util for some others functions is located here (`src/app/utils`)
